# 三角洲单挑挑战书生成器

一个基于 B 站动态「飞天狙想要努力变胖」中的《三角洲行动・单挑挑战书》模板制作的网页生成器。

## 功能

- 实时填写挑战者、应战人、对战场地、时间、定分、日期和水印文字。
- 生成带斜向半透明水印的 A4 竖版挑战书。
- 一键导出 PNG 图片和 PDF，两种格式都带有水印。
- 纯前端实现，无需后端，可直接部署到 GitHub Pages。

## 本地运行

```bash
python -m http.server 8000
```

然后打开 `http://localhost:8000`。

## 部署到 GitHub Pages

1. 将本目录推送到 GitHub 仓库。
2. 在仓库设置中开启 Pages，并选择部署分支。
3. 等待 GitHub Actions 或分支部署完成。
